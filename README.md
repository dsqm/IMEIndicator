# IMEIndicator

在文本光标左下角显示一个小提示，用来提示当前输入法状态：中英 / 大写 / 键盘布局。
纯 Win32，无依赖，主程序单 exe 即可运行。

## 运行

把 `IMEIndicator.exe` 放到想要的位置，右键以管理员身份运行

> 普通权限无法检测管理员程序的中英状态

启动后无 GUI，只在托盘显示一个字母 `I` 图标。

托盘右键菜单：

| 菜单项 | 说明 |
| --- | --- |
| 打开 GitHub 仓库 | 在浏览器打开项目主页 |
| 记录日志 | 开/关调试日志，写到 `<exe 目录>\log\IMEIndicator-<时间>.log` |
| 打开配置文件夹 | 在资源管理器里打开 exe 所在目录 |
| 设置… | 启动 `IMEIndicatorSettings.exe`（需与主程序同目录） |
| 重启程序 | 重新加载配置 |
| 退出 | 退出程序 |

启动参数：

- `--log` —— 启动即开日志（排查问题时不用先去点托盘菜单）
- `--restart` —— 通知正在运行的实例重启。设置程序保存后调它；
  设置程序以普通权限启动、主程序是管理员时会被系统拦下，退出码 2

同一时刻只允许一个实例。重复启动会弹一个提示，可以直接「打开设置」或
「退出正在运行的实例」—— 托盘图标挂不上时（任务栏拒绝注册）这是唯一的操作入口。

## 状态

11 个状态 = 键盘布局 × 输入模式 × Caps Lock。**每个状态的颜色、形状、尺寸、
偏移、透明度、开关、临时显示都能单独配** —— 大写不再是"盖掉一切"的单一颜色，
而是每种布局自己的变体。

| 状态键 | 含义 | 判定 |
| --- | --- | --- |
| `us` / `us_caps` | 美式键盘 普通 / 大写 | 布局主语言 0x09，Caps 关 / 开 |
| `cn_cn` | 中文输入法 中文 | 布局主语言 0x04，IME 处于中文 |
| `cn_en` | 中文输入法 英文 | 布局主语言 0x04，IME 处于英文 |
| `cn_caps` | 中文输入法 大写 | 布局主语言 0x04，Caps 开 |
| `jp` / `jp_caps` | 日文输入法 | 布局主语言 0x11 |
| `kr` / `kr_caps` | 韩文输入法 | 布局主语言 0x12 |
| `other` / `other_caps` | 其他布局（法/德等） | 以上都不匹配 |

判优先级：**Caps 开 → 该布局的 `*_caps`**；否则按布局判模式。没有前台窗口时
沿用上一次的状态。

## 设置程序

`IMEIndicatorSettings.exe`，与主程序放同一目录即可。分类页签：

**美式键盘 / 中文输入法 / 日文输入法 / 韩文输入法 / 其他布局 / 全局 / 黑名单**

- 顶部有实时预览条，改任何一项立刻能看到效果；右侧「预览状态」可以切换到
  任意一个状态看（切页时先落到本页第一个状态），鼠标停在上面滚轮也能逐个翻，
  滚到两头就停住
- 滑块右侧的数值可以直接输入或点「重置」恢复默认（偏移量支持负数）
- 按钮 / 复选框 / 滑块 / 下拉的圆角和圆点都是覆盖率抗锯齿画的，高 DPI 屏上
  不会露出台阶
- 大写状态默认勾选「跟随基础状态」：不单独配就跟同布局的普通状态一样。
  取消勾选时会把基础状态当前的值拷过来，视觉上不跳变
- 保存后调 `IMEIndicator.exe --restart` 让主程序重载配置；
  权限不一致导致通知失败时会提示从托盘手动重启

**为什么是独立的 exe**：主程序通常以管理员运行，设置程序需要能以普通权限
启动来写配置；设置界面出问题也不该带崩指示器。

## 配置

`<exe 目录>\IMEIndicator.json`，UTF-8。**不需要手动编辑** —— 设置程序负责读写。

- 结构：`general`（检测间隔、隐藏开关等）、`defaults`（未覆盖字段的兜底）、
  `states`（每状态覆盖项）、`ignore`（黑名单）
- 每状态字段全部可选：`enabled` / `color` / `shape` / `image` / `size` /
  `offsetX` / `offsetY` / `alpha` / `transient` / `inherit`
- `inherit` 是**整状态继承**：没显式设过的字段都跟目标状态走。
  `null` = 不继承
- 求值顺序：`状态显式值 > inherit 目标 > defaults`
- 写入用临时文件 + 改名，避免断电留下半个文件

**旧版 `IMEIndicator.ini` 自动迁移**：首次运行时读旧配置、按下面的规则换算成
JSON、把旧文件改名 `.ini.bak`。旧版 `Caps` 是独立状态，迁移时会显式写进所有
`*_caps` 并断开继承，保证行为与旧版一致。

| 旧键 | 新位置 |
| --- | --- |
| `Colors.En` / `Cn` | `cn_en` / `cn_cn` 的 `color` |
| `Colors.KbdEn` | `us` 和 `other` 的 `color` |
| `Colors.Caps` | 五个 `*_caps` 的 `color` |
| `Colors.Jp` / `Kr` | `jp` / `kr` 的 `color` |
| `Colors.Alpha` | `defaults.alpha` |
| `Overlay.Size/Shape/OffsetX/OffsetY` | `defaults.*` |
| `General.*` | `general.*` |
| `AutoHideStates` | 对应状态的 `transient` |
| 色值写 `0` | 该状态 `enabled: false` |
| `[Ignore]` | `ignore[]` |

## 显示规则

- **尺寸与偏移是逻辑像素**（96 DPI 基准），按光标所在显示器的 DPI 换算。
  旧版用物理像素，150% 屏上 20px 只有 13 逻辑像素，看起来偏小
- 形状：`none`（不显示）/ `circle` / `triangle`（等边，尖角朝上）/ `image`。
  内置形状按同一个 `size` 算（外接方形边长），换形状不用重调尺寸
- **自定义图片**：`shape: "image"` + `image: "文件名"`，图片放在
  `<exe 目录>\shapes\` 下。设置程序里点「图片…」选文件，会自动**复制**进
  `shapes\`（重名加序号，内容相同则复用）。图片原样使用、不染色，按原比例
  缩放，`size` 表示**长边**。支持 PNG / ICO / BMP / JPEG，ICO 取最大帧。
  文件缺失或解码失败时回退成圆点，设置界面里文件名标红
- `Alpha` 是每状态的不透明度，0..255
- **临时显示**：勾上后该状态只在变化后露一小会儿就消失（`autoHideMs` 控制时长，
  0 = 全部常显）。什么时候会亮：状态变化、光标坐标变化、切换窗口/焦点控件后
- `HideWhenFullscreen` —— 前景窗口全屏时不显示（看视频/演示不遮挡）
- `HideWhenComposition` —— 输入法正在打字（组合窗/候选窗出现）时隐藏，
  上屏/Esc 后自动回来
- 黑名单 —— 前台程序命中名单时**彻底隐身**：不做状态检测、不做光标查询、
  不显示提示。进程名读不到的受保护程序（内核反作弊游戏等）同样隐身
- `CaretTimeoutMs` —— 单次光标查询最长等待；超时即放弃本轮，不冻结检测线程

## 已知问题

微信输入框无文字时不显示提示。  
会造成部分游戏卡顿。可尝试将游戏进程添加至黑名单。

**托盘图标注册失败**：如果程序放在带「低完整性标签」的目录里（某些沙箱工作区会给目录打
`Mandatory Label\Low Mandatory Level`，目录下所有文件继承），非管理员启动时进程会跑在
Low 完整性，无法向任务栏发消息，`Shell_NotifyIcon` 返回拒绝访问 —— 表现为托盘没有图标。
两种解法：以管理员运行（进程提到 High，压过文件标签），或把程序**复制**（不是移动，
同卷移动会保留标签）到普通目录。

## 构建

需要 Visual Studio（MSVC x64）：

```
build.bat      # 产出 bin\IMEIndicator.exe 和 bin\IMEIndicatorSettings.exe
test.bat       # 跑配置层、形状光栅化与图片解码的单元测试
```

中间产物（`.obj` / `.res` / 测试 exe）都落在 `obj\`，`bin\` 只放成品 exe。

许可证 GPL-3.0-or-later，见 `LICENSE`。

## 自定义图片

`shapes\` 目录平铺放图，配置里只存文件名。解码一次、缓存位图，尺寸不变时
每帧零开销；源图长边超过 512 像素会先缩到这个尺寸再缓存。

`prototype/settings-ui.html` 是当初选界面布局时的一次性原型，仅作设计参考。
