# IMEIndicator

在文本光标左下角显示一个小圆点或小三角，用来提示当前输入法状态：英文 / 中文 / 大写 / 英文键盘 / 日文 / 韩文。
纯 Win32，无依赖，单 exe完全便携

## 运行

把 `IMEIndicator.exe` 放到想要的位置，双击运行 —— 只在托盘显示一个字母 `I` 图标，

托盘右键菜单：

| 菜单项  | 说明                                              |
| ---- | ----------------------------------------------- |
| 记录日志 | 开/关调试日志，写到 `<exe 目录>\log\IMEIndicator-<时间>.log` |
| 打开配置 | 用记事本打开 `IMEIndicator.ini`（改完点「重启」生效）            |
| 重启   | 重新加载配置                                          |
| 打开GitHub仓库 | 在浏览器打开项目主页                           |
| 退出   | 退出程序                                            |

启动参数：

- `--log` —— 启动即开日志（排查问题时不用先去点托盘菜单）

同一时刻只允许一个实例，重复启动会直接退出。

## 配置

首次运行会在 exe 同目录生成带注释的 `IMEIndicator.ini`（UTF-8）

- 颜色固定 `#RRGGBB`；透明度统一用 `Alpha`，颜色值不带 AA
- 色值写 `0` = 该状态**不显示**提示（默认 `Cn = 0`）
- `0` 不等于黑色 —— 黑色写 `#000000`
- 改完必须重启才生效

状态判定：

| 状态      | 判据               | 默认颜色              |
| ------- | ---------------- | ----------------- |
| Caps    | Caps Lock 打开     | 蓝 `#0080FF`       |
| KbdEn   | 键盘布局主语言为英文（0x09） | 紫 `#8B00FF`       |
| Jp      | 主语言日文（0x11）      | 黑 `#000000`       |
| Kr      | 主语言韩文（0x12）      | 黑 `#000000`       |
| Cn / En | 其余布局走 IME 中英判定   | 不显示 / 红 `#FF0000` |

- `HideWhenFullscreen = 1` —— 前景窗口全屏时不显示圆点（看视频/演示不遮挡）
- `CaretTimeoutMs = 150` —— 单次光标查询最长等待（毫秒），见下
- `Shape = circle` —— 圆点形状：`circle`（圆，默认）或 `triangle`（等边三角形，尖角朝上）。
  两种形状按同一个 `Size` 计算大小，换形状不用重新调尺寸
